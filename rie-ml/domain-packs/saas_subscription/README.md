# SaaS Subscription Management Pack

This pack contains schema, relationships, glossary, canonical rules, annotation guide, and seed feedback for a SaaS subscription management domain.

Structure mirrors other domain packs: `domain_config.json`, `taxonomy/labels.json`, `schema/`, `rules/`, `documentation/`, and `feedback/`.

Purpose: provide representative rules and seed examples for billing, subscription lifecycle, payments, and product events, suitable for RIE validation and rule-extraction work.
